# Генератор открытых уровней

В редакторе проекта откройте **Landscape → Open level generator**. Введите имя уровня и нажмите **Generate new level**. После завершения нажмите **Open generated level**. Уровень можно повторно открыть из меню сцен. Для каждого нового варианта укажите своё имя.

| Поле | Назначение |
| --- | --- |
| Heightmap | Карта высот в формате grayscale PNG, 8 или 16 бит. Без файла генератор создаёт горный хребет по Seed. Чёрный соответствует нулевой высоте, белый — значению Relief. |
| Max samples per side | Число вершин на длинной стороне генерируемой сетки. При импорте это верхняя граница. Большие карты пересчитываются билинейно. Диапазон от 2 до 1025. |
| Longest side, Relief | Размер длинной стороны и перепад высот в метрах. Шаг сетки одинаков по X и Z. Уровень центрирован относительно начала координат. |
| Distant landscape color | Цветовая карта всей поверхности в PNG или JPEG. Должна совпадать с картой высот по ориентации. Верх изображения соответствует стороне −Z, правая сторона соответствует +X. Без файла цвет строится по высоте и крутизне склонов. |
| Near detail tile | Повторяемая sRGB-текстура ближней фактуры. Она модулирует основной цвет в линейном пространстве. Нейтральный серый имеет значение около 188 из 255. Без файла создаётся зернистая фактура. |
| Detail tile size | Физический размер одного повтора ближней фактуры в метрах. |
| Fade starts, Overview only | Расстояния от камеры в метрах. До первого порога фактура имеет полную силу. Между порогами она плавно ослабевает. За вторым порогом поверхность использует одну выборку обзорной текстуры и обычное освещение сцены. |

По умолчанию уровень занимает 4096 × 4096 м. Переход идёт от 300 до 1000 м. Для фотокарты лучше подавать альбедо без сильных запечённых теней, поскольку солнце в сцене освещает рельеф отдельно. Разрешение пользовательской обзорной карты независимо от разрешения сетки. Для оценки плотности разделите ширину уровня на ширину изображения. Например, на уровне шириной 4096 м обзорная карта шириной 2048 пикселей даёт 2 м на тексель.

### Результат в проекте

Сцена сохраняется в `assets/scenes/level_<имя>.scene.json`. Она содержит стартовую камеру, солнце, небо и участки с треугольной коллизией. В `assets/landscapes/level_<имя>/` лежат 16-битная карта высот `heightmap.png`, модели участков с запечёнными LOD, общий материал и две текстуры BC7 с цепочками mip-уровней. Сохранённый PNG можно снова загрузить в генератор, например чтобы изменить масштаб или назначить другую обзорную карту.

Каждый участок охватывает до 64 × 64 ячеек. Соседние участки используют одинаковые граничные высоты, нормали и UV. Геометрический LOD выбирается движком отдельно для каждого участка. Цветовая карта покрывает весь уровень, а вклад ближней фактуры определяется расстоянием до каждой видимой точки. Поэтому на одной горе могут одновременно отображаться подробное подножие и удалённый склон.

Длинная сторона уровня может составлять от 16 м до 32 768 м. Текущая дальняя плоскость камеры движка находится в 5 км. Нужные пороги смены фактуры выбирайте в пределах видимости сцены.

### Генерация из PowerShell

Параметр `--assets` указывает на каталог ассетов целевого проекта. Путь с пробелами заключите в кавычки.

```powershell
.\build\windows-release\bin\vcr_open_level.exe --assets .\projects\my_game\assets --name highlands --seed 17
.\build\windows-release\bin\vcr_open_level.exe --assets .\projects\my_game\assets --name valley --heightmap D:\Maps\valley16.png --overview D:\Maps\valley-color.jpg --detail D:\Maps\ground.png --samples 513 --size 4096 --relief 750 --tile-size 6 --fade-start 400 --fade-end 1200
```
