# Стартовая камера и освещение сцены

Формат `vulkan_cube_scene`, версия **1**, получает два необязательных корневых
поля. Старые файлы без этих полей сохраняют прежнюю камеру `(0, 4, 12)`, yaw −90°,
pitch −12° и текущие CLI defaults освещения. Наличие обычного узла `camera` само
по себе ничего не меняет.

```json
{
  "format": "vulkan_cube_scene",
  "version": 1,
  "startup_camera": 0,
  "lighting": {"dynamic": true, "hour": 17.2, "cycle": false},
  "nodes": [
    {
      "name": "Yard entrance",
      "kind": "camera",
      "parent": null,
      "visible": true,
      "expanded": true,
      "transform": {
        "translation": [0, 3, 18],
        "rotation_degrees": [-8, 20, 0],
        "scale": [1, 1, 1]
      },
      "color": [1, 1, 1, 1]
    }
  ]
}
```

В реальной сцене также нужны узлы `directional_light` и `environment` с видимой
иерархией, чтобы renderer показывал солнце и небо. `dynamic: true` выбирает
модель солнца/неба, а `cycle: false` фиксирует час; `dynamic: false` выбирает
старый свет, не фиксированный вечер.

## Камера

`startup_camera` — целочисленный неотрицательный индекс узла `kind: "camera"`
в массиве `nodes`. Отсутствие поля означает старую камеру. `null`, строка,
неправильный тип узла и индекс за пределами массива отвергаются. При сохранении
индекс пересчитывается по порядку сериализации; в документе используется handle
с generation. Удаление выбранной камеры убирает поле при сохранении.

Позиция берётся из полного world transform камеры; родительские translation,
rotation и scale учитываются. Локальная матрица: `T * Rz * Ry * Rx * S`.
`rotation_degrees` — `[X, Y, Z]`, **градусы**, как у остальных узлов.
Направление взгляда — нормализованная мировая локальная ось `-Z`.
Видимость камеры/родителя не отключает её как стартовую точку.

Для камеры без родителей и с `Z = 0`:

- `X` задаёт pitch: положительный смотрит вверх, отрицательный вниз;
- `Y = 0` смотрит вдоль −Z, `Y = 90` вдоль −X;
- `forward = (-sin(Y)*cos(X), sin(X), -cos(Y)*cos(X))`;
- внутренний yaw FlyCamera: `atan2(forward.z, forward.x)`, pitch:
  `asin(forward.y)`; оба передаются в радианах.

FlyCamera сохраняет вертикаль мира `+Y`, не воспроизводит roll и ограничивает
pitch до ±89°. Компонента Z Euler влияет на преобразованное направление, но
крен вокруг получившегося направления не сохраняется. Нулевое/нечисловое
направление или нечисловая world matrix отвергаются при чтении.

Камера применяется при запуске runtime/editor и повторном Open сцены в editor.
Дальнейшее движение камеры не переписывает authored transform. Undo обычного
редактирования не сбрасывает текущий вид. Явный `--camera-z N` выбирает весь старый
вид `(0,4,N)`, yaw −90°, pitch −12°, даже если `N=12`. `--animate-camera` в runtime
сохраняет старую benchmark-траекторию независимо от authored camera.

## Освещение

Все поля объекта `lighting` необязательны. Значения по умолчанию и ограничения:

| Поле | Тип | Default | Допустимо |
|---|---|---|---|
| `dynamic` | bool | true | true/false |
| `voxel_gi` | bool | true | true/false; true требует dynamic |
| `cycle` | bool | true | true/false |
| `hour` | number | 14 | 0 ≤ hour < 24 |
| `day_seconds` | number | 600 | 1…864000 |
| `gi_extent` | number | 64 | 16…256 |
| `gi_strength` | number | 1 | 0…4 |
| `triangle_budget` | integer | 65536 | 1024…262144 |
| `gi_update_hz` | number | 30 | 1…120 |
| `shadow_resolution` | integer | 2048 | 1024, 2048, 4096, 8192 |

При `dynamic: false` пропущенные `voxel_gi` и `cycle` получают false. Явное
`voxel_gi: true` вместе с `dynamic: false` — ошибка. Числа должны быть конечными.
Неверный документ не заменяет уже загруженный. Save сохраняет все поля authored
lighting; отсутствие `lighting` сохраняется как отсутствие.

CLI переопределяет только явно указанные соответствующие поля. Например,
`--time-of-day 14` заменяет authored час, сохраняя authored `cycle: false`.
Выбор legacy-пути отключает GI и ход времени. Настройки применяются до создания
GPU-ресурсов. Изменение света в панели Renderer editor записывает его в документ,
помечает сцену изменённой и поддерживает Undo; Save сохраняет выбранные значения.
Автоматическое течение времени само по себе не переписывает стартовый час.

Ограничение существующего renderer: если editor стартовал без GI-ресурсов,
переключение загруженной сцены на voxel GI требует перезапуска с `--gi voxel`.
Загрузка неподдерживаемых текущей сессией настроек выдаёт диагностическую ошибку;
новая система динамического выделения GI-ресурсов в это изменение не входит.
